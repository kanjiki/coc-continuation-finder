# 候補要望の自動保存設定

保存先は次のGoogleスプレッドシートです。

- `CoC継続先候補 要望ログ`
- Spreadsheet ID: `1O6zm-V9g_CKrjd3I5Ol9aysQFgtzrNoq70OuYRQ9tmQ`
- 保存タブ: `Requests`

## 初回だけ必要な設定

1. 保存先スプレッドシートを開く。
2. `拡張機能` → `Apps Script` を開く。
3. エディタの `Code.gs` を、このリポジトリの `gas/Code.gs` の内容で丸ごと置き換える。
4. `デプロイ` → `新しいデプロイ`。
5. 種類を `ウェブアプリ` にする。
6. 実行するユーザーは自分、アクセスできるユーザーは `全員` にする。
7. デプロイ後に表示される `/exec` URL をコピーする。
8. リポジトリの `config.js` の `candidateRequestEndpoint` にそのURLを入れてCommitする。

以後、通常版・友人テスト版の「候補を送る」は、日時・元シナリオ・欲しい継続先候補・送信元だけを `Requests` へ自動追記します。名前、Xアカウント、IPアドレス等はアプリ側では収集しません。
